**Phase 1 — Build the Foundation (Months 1–3)**

**1. Hands-On Machine Learning with Scikit-Learn, Keras & TensorFlow** — _Aurélien Géron_ The single best starting point. Practical, code-first, covers the full ML pipeline from data prep to deployment. You'll write real code from page one.

**2. Python Machine Learning** — _Sebastian Raschka & Vahid Mirjalili_ Great companion to Géron's book. More rigorous on the math intuition without being overwhelming. Reinforces core concepts with clean implementations.

---

**Phase 2 — Go Deeper on Deep Learning (Months 3–6)**

**3. Deep Learning with Python** — _François Chollet_ (Keras creator) The most readable deep learning book available. Builds intuition for neural networks, CNNs, RNNs, and Transformers. Second edition covers modern architectures.

**4. Deep Learning** — _Goodfellow, Bengio & Courville_ The definitive academic reference. Dense but essential — treat it as a reference you return to, not a cover-to-cover read. Free online at deeplearningbook.org.

---

**Phase 3 — Specialize in Modern AI (Months 6–9)**

**5. Natural Language Processing with Transformers** — _Lewis Tunstall, Leandro von Werra & Thomas Wolf_ (HuggingFace team) Essential in the LLM era. Covers BERT, GPT, fine-tuning, and practical NLP pipelines using the HuggingFace ecosystem — which is now industry standard.

**6. Designing Machine Learning Systems** — _Chip Huyen_ Bridges the gap between ML models and production engineering. Covers data pipelines, training infrastructure, monitoring, and MLOps. Very relevant for SWEs.

---

**Phase 4 — Production & Systems Thinking (Months 9–12)**

**7. Machine Learning Engineering** — _Andriy Burkov_ Focused on taking models from notebooks to production systems. Written for engineers, not researchers. Short and very practical.

**8. Building Machine Learning Powered Applications** — _Emmanuel Ameisen_ Covers the full product lifecycle — scoping, prototyping, evaluation, and deployment. Great for engineers who need to ship ML features, not just build models.

---

**Bonus (Math Refresher if needed)**

**Mathematics for Machine Learning** — _Deisenroth, Faisal & Ong_ If linear algebra, calculus, and probability feel rusty, this is the best focused refresher. Also free at mml-book.github.io.

---

**The short version:** Start with Géron → Chollet → Chip Huyen. Those three alone will take you from zero to being productive on an ML team within 6 months. The rest fill in depth as you go.
